
# Project Journal

**Role:** Build, Testing, CI/CD and Deployment  
**Tech Stack:** Java 17, Spring Boot, Maven, Docker, Docker Compose, GitHub Actions, JUnit 5, Testcontainers

## Week 1: Development Environment and Build Setup

- Set up the local development environment for the API Gateway project using Java 17 and Maven.
- Reviewed the project structure and identified the dependencies required to run the gateway, database and Redis services.
- Configured the local build workflow and verified that the application compiled successfully.
- **Issue:** Local configuration differences caused inconsistent startup behaviour. Standardised the required environment variables and documented the setup process.
- **Outcome:** Established a reproducible local development setup for further integration and testing.

## Week 2: Docker-Based Environment

- Worked on the Docker configuration required to run the application alongside PostgreSQL and Redis.
- Configured Docker Compose to bring up the required services together.
- Verified database and Redis connectivity from the application.
- Documented the environment variables and commands required to start the system locally.
- **Issue:** Service startup order and connection configuration affected application initialisation. Updated the configuration and verified connectivity after startup.
- **Outcome:** Made the local multi-service environment easier to start and reproduce.

## Week 3: Automated Integration Testing

- Worked on integration tests using JUnit 5 and Testcontainers with real PostgreSQL and Redis instances.
- Tested application behaviour across database operations, Redis connectivity and rate-limit enforcement.
- Reviewed failure scenarios to ensure the system behaved according to its configured Redis failure policy.
- Documented test execution commands and the expected results.
- **Issue:** Tests depended on external container availability and correct test configuration. Standardised the test setup and investigated failures.
- **Outcome:** Improved the repeatability of integration testing and reduced dependence on manual verification.

## Week 4: Continuous Integration with GitHub Actions

- Configured and validated the GitHub Actions workflow for automated Maven builds and tests.
- Verified that changes pushed to the repository triggered the configured checks.
- Investigated build failures involving dependency resolution, test execution and container startup.
- Documented the CI workflow and the steps required to reproduce failures locally.
- **Issue:** Integration tests required Docker-backed services, which had to be available in the CI environment.
- **Outcome:** Established a repeatable build-and-test workflow for checking code changes before integration.

## Week 5: Deployment Verification and Documentation

- Worked on validating the Docker-based application deployment.
- Verified application startup, database connectivity, Redis connectivity and basic gateway functionality in the deployed environment.
- Reviewed the deployment configuration to ensure secrets and database credentials were supplied through environment variables rather than committed to the repository.
- Documented deployment steps, configuration requirements and troubleshooting procedures.
- Reviewed the build and testing workflow for gaps that could affect reproducibility.
- **Issue:** Differences between local and deployed environments could affect connectivity and startup behaviour. Documented the relevant configuration and verification steps.
- **Outcome:** Improved deployment reproducibility and documented the process for running and maintaining the application.
